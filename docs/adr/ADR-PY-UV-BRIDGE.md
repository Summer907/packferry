# ADR: 静态元数据投影交给 uv 求解

状态：按本次已批准开发计划实施；生产兼容性仍受验收矩阵约束。

## 决策

外网 PythonAdapter 使用可靠 Registry 原始制品和静态 Core Metadata 建立有界候选目录，生成仅用于 uv 求解的临时 Wheel 元数据载体。uv 负责版本约束、冲突回溯、markers 和 extras。选中结果映射回原始 Wheel/sdist；不扩展早期 B 路线的独立求解器。

## 安全与完整性

- 不运行第三方构建或安装脚本。动态或不可核实的元数据不能证明完整闭包。
- 按目标兼容标签筛选候选，不借用宿主标签。候选目录受限时报告缺口，不能将有界目录等同整个 Registry。
- 临时载体和原制品独立存储；Bundle 校验拒绝载体标记。原制品 SHA-256、身份和元数据均核实。
- 最新 sdist-only 候选无法静态求解时，保留明确 PARTIAL，不以旧 Wheel 的成功退出冒充版本优先完整结果。

## 验证边界

原文档 PoC 脚本与 evidence 文件未随当前仓库提供。本次工程测试重建本地合成样本；历史 PASS 不作为当前代码已经通过真实 Nexus、原生 ABI 或离线安装的证据。
