# Importer service

Run one Uvicorn process with `uvicorn apps.importer.server:app --host 127.0.0.1 --port 8000 --workers 1 --proxy-headers --forwarded-allow-ips <trusted-proxy-ip>`. Terminate TLS at a trusted reverse proxy and forward only the intended host and scheme. The API refuses plaintext requests and the Nexus URL must be HTTPS. `PACKFERRY_ALLOW_INSECURE_HTTP=1` is for local tests only.

Configuration can come from `PACKFERRY_CONFIG` (YAML) with fields `data_dir`, `nexus_url`, `repositories` (name to `pypi` or `npm`), `maintainers`, `max_bundle_bytes`, and `bundle_retention_days`. Environment overrides use `PACKFERRY_DATA_DIR`, `PACKFERRY_NEXUS_URL`, `PACKFERRY_REPOSITORIES_JSON`, `PACKFERRY_MAINTAINERS`, `PACKFERRY_MAX_BUNDLE_BYTES`, and `PACKFERRY_BUNDLE_RETENTION_DAYS`. Passwords are supplied only at login or reauthorization and never belong in this configuration.

The service uses SQLite WAL and a single in-process worker. Upload returns `READY`; confirmation queues it. After restart, queued or interrupted tasks become `NEEDS_AUTH`; the original owner must call `/api/v1/imports/{id}/authorize`. Unknown file outcomes are reconciled against remote bytes. If remote absence follows an uncertain upload, that file stays `UNKNOWN` and a fresh task is required. Terminal task reports and audit survive Bundle cleanup. Completed task ZIP files are removed after 30 days by default; live and pending tasks remain.

Use `python -m apps.importer.maintenance backup --data-dir /var/lib/packferry --output /backups/packferry.zip` for a consistent SQLite snapshot plus retained Bundle files. Add `--config /path/to/importer.yaml` to include only approved nonsecret configuration fields. Backup, upload publication to local storage, and cleanup share a cross-process file lock so every backup contains the ZIP files referenced by its database snapshot. Stop the service before restoring the archive to its original data directory. Check file ownership and run the service with the same configured data directory. Database migrations are in `apps/importer/migrations`; run `alembic -c apps/importer/alembic.ini upgrade head` before starting an upgraded deployment.

The Nexus 3.96.4 CE identity, PyPI and npm wire behavior must be checked against the actual production instance before rollout. Local tests use an isolated fake Nexus and do not establish this compatibility.
